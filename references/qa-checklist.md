# 交付前质量检查

## 内容

- [ ] 页数与源文件一致；没有缺页、重复页或空白页。
- [ ] 标题、摘要、关键词、正文、图题、表题、脚注、致谢及章节标题均已覆盖。
- [ ] 术语、缩写和机构名称全文一致。
- [ ] 数值、正负号、有效数字、单位、变量、公式编号、图表编号和引用编号与原文一致。
- [ ] 作者、期刊、DOI、标准号和参考文献著录项保持可检索。

## 版式

- [ ] 页面尺寸、方向、栏数、分页和主要对象位置保持一致。

- [ ] 字体已嵌入，所有中文字符可见且无方框或乱码。

## 图表与表征

- [ ] 所有原始图片仍存在，分辨率和裁切未被意外改变。
- [ ] 图题、图例、坐标轴、流程框、子图标题及可辨识标签已翻译。

- [ ] 公式及上下标、希腊字母、矩阵、分式和编号完整。

## 视觉核验

- [ ] 已渲染全部页面并检查总览图。
- [ ] 已逐页检查正文和图表，没有大块英文正文残留。
- [ ] 已按高倍率检查复杂图表页、公式页、密集表格页、首页、末页和参考文献页。
