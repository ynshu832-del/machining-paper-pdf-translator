# 保版翻译工作流

## 1. 建立源文件清单

记录页数、页面尺寸与旋转、单双栏结构、文本层质量、字体、图片、表格、公式、脚注、超链接、书签、扫描页及加密状态。先渲染全部页面生成总览图，识别复杂页和异常页。

## 2. 选择页面处理策略

- **可提取文本 PDF**：优先保留原页面对象，在原文本区域精确覆盖或移除英文，再写入中文。
- **扫描或轮廓化 PDF**：对页面和图内文字 OCR，保存文字、坐标、置信度与阅读顺序；低置信度内容必须人工核对。
- **混合 PDF**：正文按文本块处理，位图图表按 OCR 标签处理。不要为了方便把整篇论文全部栅格化。

建立稳定的块标识，例如 `页码-栏位-顺序`。翻译映射至少保存原文、译文、页码、边界框和对象类型，便于逐项追踪和返工。

## 3. 翻译顺序

1. 标题、摘要、关键词和章节标题；据此确定学科语域和术语表。
2. 正文、列表、脚注和致谢；保持交叉引用和引用编号。
3. 图题、表题、表头和表注。
4. 图内标签、坐标轴、图例、流程框及子图标题。
5. 元数据中适合翻译的标题与主题字段；作者、期刊和 DOI 保持可检索。

段落翻译以“技术含义等值”为目标。不要增加原文没有的因果、评价或实验结论。遇到歧义时根据公式、图表、方法和上下文判定；仍无法确认则保留原词并标注待核验。

## 4. 回填版面

- 使用支持简体中文且可嵌入的字体。正文、标题、图题和表格分别建立字号层级。
- 先按原文本框宽高排版；若溢出，依次尝试中文断句、压缩段前后距、微调行距、轻微缩小字号。不得牺牲可读性把正文压成极小字体。
- 双栏论文必须保持栏间距和阅读顺序。不要让译文跨栏或覆盖页眉页脚。
- 覆盖英文时只处理实际文字区域。白底可用精确遮罩；彩色、渐变或纹理背景使用局部背景匹配或矢量文本替换，避免遮住网格线、箭头和曲线。
- 保留原链接、DOI 和引用编号的可用性；可重建被覆盖文本的链接注释。

## 5. 图、表、公式与表征结果

### 图和图内文字

- OCR 结果需按图像原分辨率核对。常见误识别包括 `0/O`、`1/l/I`、负号、微米符号、希腊字母和上下标。
- 文本标签译文放在原标签位置或同一局部空白区域，不得移动子图、比例尺、图例、箭头、引线或色条。
- 坐标轴变量和单位保持不变，只翻译描述性词语。`Time (s)` 可译为 `时间 (s)`，但变量 `t`、单位 `s` 不变。
- 无法可靠识别的细小或低对比度标签保留原文，不猜测，不删除。

### 表格

- 保留表号、列序、行序、合并关系、脚注标记、有效数字和单位。
- 翻译表头及描述性单元格；纯数值、数学符号、材料牌号和样品编号保持原样。
- 回填后逐行核对，尤其检查负号、小数点和科学计数法是否被遮盖或换行拆分。

### 公式

- 公式、变量、上下标、运算符和编号作为不可改写对象保留。
- 仅翻译公式前后的说明以及 `where` 后的变量释义。
- 若必须重绘，使用数学排版，并与原式逐字符核对；不可依据常识补全原文中模糊的项。

### 显微与光谱表征

- 不修改 SEM、EDS、XRD、Raman、AFM、EBSD 等原始图像数据。
- 保留比例尺、峰位、元素符号、晶面指数、色标范围和统计误差；只替换说明性英文。
- 子图编号 `(a)–(f)` 与正文引用必须一致。

## 6. 回退与停止条件

- PDF 损坏、缺页、需要未知密码或关键页无法渲染：停止并说明阻塞。
- 中文无法在原区域内保持可读：优先建议用户选择“原分页近似保版”或“可读性优先重排”，不要静默改变整篇布局。
- 图内关键标签 OCR 置信度不足且无法从正文核实：保留原文并报告页码与图号。
- 自动检查通过不等于完成。必须进行逐页视觉检查后才能交付。
